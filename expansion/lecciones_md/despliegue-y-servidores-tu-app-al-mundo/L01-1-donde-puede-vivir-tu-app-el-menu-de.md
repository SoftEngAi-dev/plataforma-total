## 📝 Quiz de la lección

### 1. ¿Cuál es la forma MÁS rápida de publicar una web estática hoy?
- A) Comprar un VPS
- B) GitHub Pages / Netlify: arrastrar la carpeta o conectar el repo, gratis con HTTPS
- C) AWS
- D) IIS
### 2. ¿Qué diferencia un VPS de un PaaS?
- A) Precio solamente
- B) VPS = tú administras todo (más control y aprendizaje); PaaS = ellos administran, tú solo das el código (menos fricción)
- C) El VPS es la nube
- D) Son iguales

---

## 🔑 Respuestas y explicaciones

**1.** ✅ GitHub Pages / Netlify: arrastrar la carpeta o conectar el repo, gratis con HTTPS — El hoy: no necesitas ni servidor: tu carpeta ya es una web mundial.
**2.** ✅ VPS = tú administras todo (más control y aprendizaje); PaaS = ellos administran, tú solo das el código (menos fricción) — Elige VPS para APRENDER sistemas; PaaS para enfocarte en producto.
