## 📖 Contenido

```html
HTML: ESTRUCTURA, NO DECORACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HTML (HyperText Markup Language) define QUÉ ES cada cosa: un título, un párrafo, un botón. La decoración es tarea de CSS.

ANATOMÍA DE UNA ETIQUETA
  <etiqueta atributo="valor">contenido</etiqueta>
  <p class="nota">Hola</p>          ← p es etiqueta, class es atributo

DOCUMENTO MÍNIMO
  <!DOCTYPE html>
  <html lang="es">
    <head><meta charset="utf-8"><title>Mi página</title></head>
    <body><h1>¡Hola mundo web!</h1></body>
  </html>

LAS 12 QUE USARÁS SIEMPRE
```

## 📝 Quiz de la lección

### 1. ¿Qué define HTML en una página web?
- A) Los colores y tipografías
- B) La estructura y el significado del contenido
- C) La lógica interactiva
- D) La base de datos
### 2. ¿Para qué sirve <head> en un documento HTML?
- A) Mostrar el encabezado visible
- B) Metadatos: title, charset, enlaces a CSS/JS — no se muestra en la página
- C) El menú de navegación
- D) Nada, es opcional

---

## 🔑 Respuestas y explicaciones

**1.** ✅ La estructura y el significado del contenido — HTML = estructura/semántica; CSS = presentación; JS = comportamiento.
**2.** ✅ Metadatos: title, charset, enlaces a CSS/JS — no se muestra en la página — Todo lo de <head> configura la página; lo visible vive en <body>.
