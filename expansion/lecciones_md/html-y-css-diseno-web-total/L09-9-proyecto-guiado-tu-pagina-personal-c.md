## 📝 Quiz de la lección

### 1. ¿Cuál es el éxito mínimo del proyecto?
- A) Que gane un premio de diseño
- B) Que se vea bien tanto en móvil como en desktop
- C) Que use 10 fuentes distintas
- D) Que tenga animaciones complejas
### 2. ¿Qué combinación cubre los layouts del proyecto?
- A) Solo floats
- B) Flexbox para el nav + Grid para las tarjetas
- C) Tablas HTML
- D) Solo posición absoluta

---

## 🔑 Respuestas y explicaciones

**1.** ✅ Que se vea bien tanto en móvil como en desktop — Responsive sólido es la meta; el gusto se entrena después.
**2.** ✅ Flexbox para el nav + Grid para las tarjetas — Flex para 1 dimensión (nav), Grid para 2 (cards): la receta moderna.
