## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué hace `git push -u origin main`?** → Sube tus commits y enlaza la rama local con la remota para futuros pushes _(El -u solo hace falta la primera vez; después, `git push` a secas.)_
- **¿Qué es un Pull Request?** → Proponer cambios de una rama para que otros los revisen antes de fusionar _(PR = cambio propuesto + revisión + discusión + fusión: la base del trabajo en equipo.)_
