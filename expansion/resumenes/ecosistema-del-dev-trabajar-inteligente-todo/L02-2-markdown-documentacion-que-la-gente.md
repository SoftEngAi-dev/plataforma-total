# ⚡ Cheatsheet — 2. Markdown + documentación que La gente lee

> Ecosistema del Dev — Trabajar Inteligente Todos los Días · Lección 2 · 18/09/2026

## 💡 Idea central
DOCUMENTAR = PENSALO DOS VECES (TU CARRERA LO NOTARÁ)

## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué debe comentar un buen comentario en código?** → El POR QUÉ/contexto no obvio del código (el QUÉ lo dice el código mismo) _(Razones, advertencias y decisiones: lo que futuras lecturas no pueden inferir.)_
- **¿Cuál es la estructura de un README que convierte?** → Qué hace + demo + install 3 pasos + ejemplo de uso (el lector decide en <1 minuto) _(La claridad al abrir = usuarios/contribuidores que se quedan.)_

## 🔁 Repaso espaciado sugerido
Hoy → mañana → dentro de 3 días → dentro de una semana. 5 minutos bastan.
