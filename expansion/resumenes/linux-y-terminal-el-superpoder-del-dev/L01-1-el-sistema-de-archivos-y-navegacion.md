## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué hace mkdir -p a/b/c?** → Crea la ruta completa incluidos padres intermedios sin error _(Sin -p falla si 'a' no existe; con -p crea todo el camino.)_
- **rm -r lo que hace peligroso es que...** → Linux NO tiene papelera: lo borrado por rm se fue (por eso rm -i o trash tools) _(Cuidado con rm: la ruta / o comodines mal puestos borran todo sin preguntar.)_
