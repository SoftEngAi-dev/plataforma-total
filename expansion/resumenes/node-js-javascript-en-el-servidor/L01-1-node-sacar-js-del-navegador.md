## 💡 Idea central
NODE: V8 EN LA TERMINAL

## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué es Node.js?** → Un runtime que ejecuta JS fuera del navegador (motor V8) _(Mismo motor V8 de Chrome, liberado para servidores y scripts.)_
- **¿Cómo activar ES Modules (import/export) en Node?** → "type": "module" en package.json (o usar .mjs) _(Con esa flag, import from 'node:fs/promises' y top-level await funcionan nativamente.)_
