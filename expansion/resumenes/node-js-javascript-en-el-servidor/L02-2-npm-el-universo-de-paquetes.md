## 🧠 Autoexamen (tápate la respuesta)
- **¿Por qué node_modules NUNCA va a git?** → Es enorme y reproducible: package.json + package-lock permiten recrearlo con npm install _(El manifiesto viaja; el contenido se instala. Así mantienen repos livianos TODOS los equipos.)_
- **¿Qué significa "express": "^4.19.2"?** → Cualquier versión 4.x.x compatible desde 4.19.2 _(^ permite parches y menores compatibles; el lock file congela la realidad exacta.)_
