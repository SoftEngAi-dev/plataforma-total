# ⚡ Cheatsheet — 1. HTML: el esqueleto de toda la web

> HTML y CSS — Diseño Web Total · Lección 1 · 18/09/2026

## 💡 Idea central
HTML: ESTRUCTURA, NO DECORACIÓN

## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué define HTML en una página web?** → La estructura y el significado del contenido _(HTML = estructura/semántica; CSS = presentación; JS = comportamiento.)_
- **¿Para qué sirve <head> en un documento HTML?** → Metadatos: title, charset, enlaces a CSS/JS — no se muestra en la página _(Todo lo de <head> configura la página; lo visible vive en <body>.)_
