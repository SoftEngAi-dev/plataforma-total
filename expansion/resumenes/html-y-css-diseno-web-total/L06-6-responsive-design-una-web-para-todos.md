## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué hace la meta etiqueta viewport?** → Dice al móvil que use el ancho real del dispositivo y no una miniatura _(Sin ella, el móvil renderiza como si fuera un desktop de 980px y escala.)_
- **¿Qué significa mobile-first?** → Escribir el CSS base para móvil y crecer con min-width media queries _(Base simple en pantalla chica; complejidad progresiva hacia pantallas grandes.)_
