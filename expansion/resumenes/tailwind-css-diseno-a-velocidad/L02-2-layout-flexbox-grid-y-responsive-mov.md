## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué significa la clase md:grid-cols-3?** → 3 columnas a partir del breakpoint md (768px) hacia arriba _(Tailwind es mobile-first: el base es móvil y los prefijos md:/lg: aplican hacia arriba.)_
- **¿Cómo centras horizontalmente un contenedor con ancho máximo?** → con la clase mx-auto (más max-w-* o container) _(mx-auto reparte el margen lateral; text-center solo alinea texto en línea.)_
