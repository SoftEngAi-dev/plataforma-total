## 🧠 Autoexamen (tápate la respuesta)
- **¿Por qué el few-shot (dar ejemplos input→output) mejora tanto?** → El modelo imita el FORMATO Y EL PATRÓN de tus ejemplos en vez de adivinar _(2-3 ejemplos concretos enseñan estilo/estructura mejor que 10 instrucciones abstractas.)_
- **¿Cuál prompt funciona mejor para debugging?** → Pegar el código + el traceback completo + qué esperabas que pasara _(Sin datos concretos el modelo adivina; con contexto real = respuesta de cirujano.)_
