## 💡 Idea central
TRABAJAR CON OTROS SIN PISARSE

## 🧠 Autoexamen (tápate la respuesta)
- **¿Cuál es el ciclo correcto de contribución?** → rama → commits → push → PR → revisión → merge _(El PR con revisión es el corazón del trabajo en equipo moderno.)_
- **¿Cuándo necesitas hacer fork?** → Cuando el repo no es tuyo/no tienes permiso de push (open source) _(Fork = tu copia en tu cuenta, que permite proponer PR al original.)_
