- **¿Por qué .env va al .gitignore SIEMPRE?** → Contiene secretos (claves, tokens) que jamás deben quedar en la historia pública _(Un secreto subido = filtrado para siempre, aunque lo borres después: hay que rotar la credencial.)_
- **¿Qué es un tag v1.0 en git?** → Una marca permanente sobre un commit: la forma de publicar releases/versiones _(Los tags señalan hitos estables; son referencia para despliegues.)_
