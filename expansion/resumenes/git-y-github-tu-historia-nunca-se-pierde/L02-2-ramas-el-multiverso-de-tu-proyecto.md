## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué es un merge conflict?** → Dos ramas editaron las mismas líneas: git te pide elegir manualmente entre marcadores <<<< _(Los conflictos son decisiones pendientes, no errores: resuelves, add, commit.)_
- **¿Por qué ramas cortas de 1-3 días?** → Cambios pequeños = conflictos raros y merges simples; la rama eterna deviene imposible de integrar _(La integración continua empieza por ramas efímeras.)_
