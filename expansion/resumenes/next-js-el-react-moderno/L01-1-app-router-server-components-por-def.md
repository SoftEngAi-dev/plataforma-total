## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué es un React Server Component en Next.js App Router?** → Un componente que se renderiza en el servidor y no envía su JS al cliente _(Corre en el servidor: puede usar async/await y recursos backend sin exponerlos al navegador.)_
- **¿Qué archivo crea la ruta /dashboard en el App Router?** → app/dashboard/page.tsx _(En app/, cada carpeta con page.tsx es una ruta; layouts y loading se anidan por segmento.)_
