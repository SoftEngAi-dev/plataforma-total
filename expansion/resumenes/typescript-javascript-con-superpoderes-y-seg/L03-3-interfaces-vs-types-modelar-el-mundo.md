## 🧠 Autoexamen (tápate la respuesta)
- **¿Cuándo elegir interface sobre type?** → Para formas de objetos: más legible, mensajes de error claros y extensión natural _(Interface para modelos de dominio; type para uniones y composiciones.)_
- **¿Qué expresa type Estado = "cargando" | "ok" | "error"?** → Una unión de literales: la variable solo vale uno de esos strings _(Uniones de literales = estados exhaustivos que TS puede verificar (sin strings sueltos).)_
