## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué hace const { nombre } = alumno?** → Extrae alumno.nombre en una variable llamada nombre (destructuring) _(Destructuring: la forma idiomática de extraer propiedades en JS moderno.)_
- **¿Cuándo usar alumno["nombre"] en vez de alumno.nombre?** → Cuando la clave viene de una variable o tiene espacios _(Los corchetes aceptan expresiones: alumno[variable] resuelve la clave dinámicamente.)_
