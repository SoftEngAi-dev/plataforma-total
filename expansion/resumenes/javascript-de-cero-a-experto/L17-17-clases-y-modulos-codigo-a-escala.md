## 🧠 Autoexamen (tápate la respuesta)
- **¿Qué hace export default frente a export nombrado?** → Un solo default por archivo, se importa sin llaves; los nombrados van con llaves exactas _(import X from... (default) vs import { x } from... (nombrados).)_
- **¿Qué hace super.completar() en una subclase?** → Invoca la versión del método en la clase padre _(super = acceso a la clase padre: reutilizas y extiendes en vez de reescribir.)_
