# 📖 Glosario — 5. GitHub: publica y colabora

> Herramientas del Desarrollador · Lección 5 · Términos que debes poder definir sin mirar

- **Sube tus commits y enlaza la rama local con la remota para futuros pushes** — El -u solo hace falta la primera vez; después, `git push` a secas.
- **Proponer cambios de una rama para que otros los revisen antes de fusionar** — PR = cambio propuesto + revisión + discusión + fusión: la base del trabajo en equipo.
