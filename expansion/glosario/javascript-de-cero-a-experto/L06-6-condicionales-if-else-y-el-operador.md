# 📖 Glosario — 6. Condicionales: if, else y el operador ternario

> JavaScript — De Cero a Experto · Lección 6 · Términos que debes poder definir sin mirar

- **false, 0, "", null, undefined, NaN** — if(x) con x falsy no ejecuta el bloque — revisa esta lista cuando te sorprenda.
- **Usa "invitado" SOLO si nombre es null o undefined (no si es "" o 0)** — ?? es el default preciso: || también rechazaría '' y 0 que podrías querer conservar.
