# 📖 Glosario — 8. Funciones y arrow functions: el corazón de JS

> JavaScript — De Cero a Experto · Lección 8 · Términos que debes poder definir sin mirar

- **undefined** — Sin return explícito, toda función JS devuelve undefined.
- **No tiene su propio this: usa el del contexto que la rodea** — Crucial en callbacks y objetos: la arrow no 'secuestra' el this como hace function.
