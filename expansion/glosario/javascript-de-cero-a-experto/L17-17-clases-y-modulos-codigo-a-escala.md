# 📖 Glosario — 17. Clases y módulos: código a escala

> JavaScript — De Cero a Experto · Lección 17 · Términos que debes poder definir sin mirar

- **Un solo default por archivo, se importa sin llaves; los nombrados van con llaves exactas** — import X from... (default) vs import { x } from... (nombrados).
- **Invoca la versión del método en la clase padre** — super = acceso a la clase padre: reutilizas y extiendes en vez de reescribir.
