# 📖 Glosario — 3. Tipos de datos y operadores

> JavaScript — De Cero a Experto · Lección 3 · Términos que debes poder definir sin mirar

- **== convierte tipos automáticamente y genera bugs sutiles; === compara valor y tipo** — "5" == 5 da true; con === da false. Predicibilidad > comodidad.
- **null** — null = 'vacío a propósito'; undefined = 'aún no se le asignó nada'.
