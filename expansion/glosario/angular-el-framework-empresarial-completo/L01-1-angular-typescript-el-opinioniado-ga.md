# 📖 Glosario — 1. Angular + TypeScript: el opinioniado ganador empresa

> Angular — El Framework Empresarial Completo · Lección 1 · Términos que debes poder definir sin mirar

- **Angular es framework COMPLETO con router/http/form/DI incluidos y TypeScript obligatorio; React es librería de vista + ecosistema a elección** — Batteries-included vs composición libre: dos filosofías válidas según equipo y proyecto.
- **{{ }} interpola valores al HTML; (evento)="fn()" enlaza eventos a métodos del componente** — La sintaxis template de Angular: imprimir con {{}} y escuchar con () encadenado a la clase TS.
