# 📖 Glosario — 3. Renderizar listas y condicionales

> React — Interfaces Modernas y Reutilizables · Lección 3 · Términos que debes poder definir sin mirar

- **key: identidad estable entre renders para emparejar el DOM correctamente** — La key es DNI, no apellido: el índice del map cambia y traiciona con listas dinámicas.
- **Operador &&, ternario, o variable calculada ANTES del return** — JSX admite expresiones, no sentencias: la lógica va en expresiones o antes del return.
