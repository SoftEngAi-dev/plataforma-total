# 📖 Glosario — 8. Proyecto: app de notas con todo el curso

> React — Interfaces Modernas y Reutilizables · Lección 8 · Términos que debes poder definir sin mirar

- **map que devuelve objeto nuevo {...n, texto: x} solo para el id coincidente** — map con spread: reemplazas el objeto con uno NUEVO; referencias nuevas → React entiende y la UI se actualiza.
- **useState + useEffect dentro de un custom hook useLocalStorage** — Estado + efecto que escribe a localStorage: patrón simple, potente y reutilizable.
