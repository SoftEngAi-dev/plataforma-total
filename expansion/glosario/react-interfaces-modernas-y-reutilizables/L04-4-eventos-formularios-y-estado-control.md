# 📖 Glosario — 4. Eventos, formularios y estado controlado

> React — Interfaces Modernas y Reutilizables · Lección 4 · Términos que debes poder definir sin mirar

- **Su value viene del estado y onChange lo actualiza: el estado es la fuente de verdad** — Estado ↔ input en bucle controlado. React manda; el DOM obedece.
- **Llama a una función que el padre le pasó por props (onAgregar)** — Datos bajan por props; cambios suben ejecutando callbacks que bajaron por props.
