# 📖 Glosario — 6. Composición, context y custom hooks: las 3 escaleras

> React — Interfaces Modernas y Reutilizables · Lección 6 · Términos que debes poder definir sin mirar

- **Cuando muchos componentes a mucha profundidad necesitan el mismo dato (tema, usuario, idioma)** — Context resuelve prop-drilling global; estado local y composición resuelven la mayoría de los casos.
- **Top-level del componente, sin loops/ifs, nombres use*** — El orden fijo de llamadas es cómo React empareja hook con celda de estado: romperlo = caos.
