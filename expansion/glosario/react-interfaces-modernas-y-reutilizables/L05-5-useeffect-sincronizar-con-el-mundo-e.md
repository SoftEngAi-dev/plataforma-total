# 📖 Glosario — 5. useEffect: sincronizar con el mundo exterior

> React — Interfaces Modernas y Reutilizables · Lección 5 · Términos que debes poder definir sin mirar

- **Una vez al montar el componente** — Array vacío = sin dependencias: solo el montaje. La limpieza corre al desmontar.
- **Cancelar trabajo pendiente (fetch, timers, subscripciones) antes de re-ejecutar o desmontar** — Evita race conditions y fugas: la respuesta tardía de un fetch viejo no pisa la nueva.
