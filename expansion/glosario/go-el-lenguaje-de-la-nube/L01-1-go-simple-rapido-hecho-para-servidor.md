# 📖 Glosario — 1. Go: simple, rápido, hecho para servidores

> Go — El Lenguaje de la Nube · Lección 1 · Términos que debes poder definir sin mirar

- **Genera UN binario nativo sin dependencias externas: el despliegue es copiar un archivo** — Un solo ELF/EXE estático: las imágenes docker de Go pueden pesar 5MB.
- **Declarar variable nueva con tipo INFERIDO (vs var x int explícita para el init)** — x := 5 = declarar+inicializar inferido; var para declaraciones sin valor inicial.
