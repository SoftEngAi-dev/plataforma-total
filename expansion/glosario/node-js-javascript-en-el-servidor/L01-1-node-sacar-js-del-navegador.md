# 📖 Glosario — 1. Node: sacar JS del navegador

> Node.js — JavaScript en el Servidor · Lección 1 · Términos que debes poder definir sin mirar

- **Un runtime que ejecuta JS fuera del navegador (motor V8)** — Mismo motor V8 de Chrome, liberado para servidores y scripts.
- **"type": "module" en package.json (o usar .mjs)** — Con esa flag, import from 'node:fs/promises' y top-level await funcionan nativamente.
