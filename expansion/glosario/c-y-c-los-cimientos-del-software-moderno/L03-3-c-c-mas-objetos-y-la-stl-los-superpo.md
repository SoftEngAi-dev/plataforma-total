# 📖 Glosario — 3. C++: C más objetos y la STL (los superpoderes)

> C y C++ — Los Cimientos del Software Moderno · Lección 3 · Términos que debes poder definir sin mirar

- **Array dinámico gestionado: crece solo, sabe su tamaño, sin malloc/free manual** — vector + string + sort + map = la STL: productividad C++, sin pelear malloc manual.
- **Adquisición/liberación de recursos ligada al ciclo de vida de objetos: scope-ended = recurso liberado (origen del modelo que perfecciona Rust)** — Destructor al salir del bloque: no olvidas liberar; es la contra a los leaks/locks olvidados.
