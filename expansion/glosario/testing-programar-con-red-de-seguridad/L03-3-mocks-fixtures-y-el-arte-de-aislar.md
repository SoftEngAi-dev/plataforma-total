# 📖 Glosario — 3. Mocks, fixtures y el arte de aislar

> Testing — Programar con Red de Seguridad · Lección 3 · Términos que debes poder definir sin mirar

- **Cuando tu función llama a algo EXTERNO (red/BD/tiempo) y quieres probar solo tu lógica con respuestas controladas** — El mock convierte tu entorno en laboratorio: mismos datos, siempre, instantáneo.
- **La preparación compartida entre muchos tests (datos de prueba, conexiones, objetos complejos)** — Fixture = DRY aplicado a tests: un usuario demo se define una vez y todos lo usan.
