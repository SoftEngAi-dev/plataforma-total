# 📖 Glosario — 2. Pytest, Jest y asserts: la gramática universal

> Testing — Programar con Red de Seguridad · Lección 2 · Términos que debes poder definir sin mirar

- **Arrange (preparar datos) → Act (ejecutar lo probado) → Assert (verificar el resultado)** — Estructura legible y consistente: la legibilidad de los tests es deuda evitada.
- **Verifica que el código LANZA esa excepción concreta — test del comportamiento de error** — Probar los caminos de error es tan importante (o más) que el camino feliz.
