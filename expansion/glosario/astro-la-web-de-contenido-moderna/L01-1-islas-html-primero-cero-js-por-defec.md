# 📖 Glosario — 1. Islas: HTML primero, cero JS por defecto

> 🚀 Astro — La Web de Contenido Moderna · Lección 1 · Términos que debes poder definir sin mirar

- **Solo HTML + CSS estático (cero JS)** — Esa es su superpotencia: HTML estático sin JS salvo que añadas islas interactivas.
- **Componentes interactivos que se hidratan de forma aislada** — Una isla (con client:load/visible…) se hidrata sola: el resto de la página sigue siendo HTML estático.
