# 📖 Glosario — 2. 'use client': el borde servidor/navegador

> ▲ Next.js — El React Moderno · Lección 2 · Términos que debes poder definir sin mirar

- **Usar useState, useEffect o manejadores como onClick** — Esas APIs son del navegador; sin la directiva el componente se trata como Server Component y falla.
- **En los componentes hoja interactivos, lo más abajo posible** — Cuanto más abajo, menos JS viaja: el resto del árbol permanece como Server Components.
