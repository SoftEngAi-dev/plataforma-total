- **Un componente que se renderiza en el servidor y no envía su JS al cliente** — Corre en el servidor: puede usar async/await y recursos backend sin exponerlos al navegador.
- **app/dashboard/page.tsx** — En app/, cada carpeta con page.tsx es una ruta; layouts y loading se anidan por segmento.
