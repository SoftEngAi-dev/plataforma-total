# 📖 Glosario — 2. Diseñar tu API: recursos, URLs y convenciones

> APIs REST y HTTP — El Idioma de los Servidores · Lección 2 · Términos que debes poder definir sin mirar

- **/api/tareas (sustantivo plural; la ACCIÓN va en el método HTTP, no en la URL)** — Recursos=sustantivos; acciones=GET/POST/PATCH/DELETE: esa es la legibilidad REST.
- **El cliente recibe inmediato el objeto recién creado CON su id asignado; sin nueva llamada gratuita** — El status informa lo ocurrido + la respuesta entrega el valor resultante.
