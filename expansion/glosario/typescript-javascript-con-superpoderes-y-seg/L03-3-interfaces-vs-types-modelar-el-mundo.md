# 📖 Glosario — 3. Interfaces vs Types: modelar el mundo

> TypeScript — JavaScript con Superpoderes y Seguridad · Lección 3 · Términos que debes poder definir sin mirar

- **Para formas de objetos: más legible, mensajes de error claros y extensión natural** — Interface para modelos de dominio; type para uniones y composiciones.
- **Una unión de literales: la variable solo vale uno de esos strings** — Uniones de literales = estados exhaustivos que TS puede verificar (sin strings sueltos).
