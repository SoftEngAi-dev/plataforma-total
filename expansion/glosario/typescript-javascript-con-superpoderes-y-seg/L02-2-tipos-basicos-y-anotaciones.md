# 📖 Glosario — 2. Tipos básicos y anotaciones

> TypeScript — JavaScript con Superpoderes y Seguridad · Lección 2 · Términos que debes poder definir sin mirar

- **Cuando la inferencia no es obvia (y siempre en firmas de funciones públicas)** — TS infiere en la asignación; anota donde el contrato importa.
- **any desactiva toda verificación; unknown exige comprobar el tipo antes de usarlo** — unknown = 'no sé aún, pero TS me protege'; any = 'ríndete, compilador'.
