# 📖 Glosario — 4. Genéricos: reusabilidad con seguridad

> TypeScript — JavaScript con Superpoderes y Seguridad · Lección 4 · Términos que debes poder definir sin mirar

- **Recuerda el tipo exacto de entrada y lo devuelve: autocomplete y chequeo completos** — Los genéricos modelan RELACIONES entre tipos — any solo las borra.
- **Restringe T a tipos que tengan la propiedad length** — Constraint: puedo usar .length sabiendo que el compilador lo garantiza.
