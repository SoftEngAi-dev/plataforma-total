# 📖 Glosario — 3. Spring Boot: API REST en 15 líneas de verdad

> Java y Spring — El Backend del Mundo Empresarial · Lección 3 · Términos que debes poder definir sin mirar

- **Declara la clase como controlador web: los métodos responden HTTP y devuelven datos serializados (JSON)** — @RestController = @Controller + @ResponseBody: todo método = respuesta JSON directa.
- **El framework crea y entrega los objetos que necesita tu clase por el constructor: cambiar implementación sin tocar tu código** — Recibes lo que necesitas; no lo construyes: testeo con mocks y evolución sin drama.
