# 📖 Glosario — 4. Spring Data JPA: base de datos casi gratis

> Java y Spring — El Backend del Mundo Empresarial · Lección 4 · Términos que debes poder definir sin mirar

- **Spring Data genera la query automáticamente a partir del NOMBRE del método (derivada por convención)** — Query derivation: nombras bien el método, la query existe sin escribirla.
- **Marca la clase como tabla de BD manejada por el ORM (cada instancia = fila)** — El mapeo objeto-relacional (ORM): objetos Java ↔ filas SQL.
