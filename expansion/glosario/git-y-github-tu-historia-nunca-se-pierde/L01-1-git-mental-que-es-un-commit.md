# 📖 Glosario — 1. Git mental: qué es un commit

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 1 · Términos que debes poder definir sin mirar

- **Un snapshot completo del proyecto con puntero al commit padre** — Cada commit = foto completa; git las deduplica internamente (objetos).
- **editar → git add → git commit** — Working → staging (add) → repo (commit). push va aparte al remoto.
