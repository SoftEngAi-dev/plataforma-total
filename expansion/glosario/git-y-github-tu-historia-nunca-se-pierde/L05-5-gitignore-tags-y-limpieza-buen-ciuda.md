# 📖 Glosario — 5. .gitignore, tags y limpieza: buen ciudadano del repo

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 5 · Términos que debes poder definir sin mirar

- **Contiene secretos (claves, tokens) que jamás deben quedar en la historia pública** — Un secreto subido = filtrado para siempre, aunque lo borres después: hay que rotar la credencial.
- **Una marca permanente sobre un commit: la forma de publicar releases/versiones** — Los tags señalan hitos estables; son referencia para despliegues.
