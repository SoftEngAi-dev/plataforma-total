# 📖 Glosario — 2. Ramas: el multiverso de tu proyecto

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 2 · Términos que debes poder definir sin mirar

- **Dos ramas editaron las mismas líneas: git te pide elegir manualmente entre marcadores <<<<** — Los conflictos son decisiones pendientes, no errores: resuelves, add, commit.
- **Cambios pequeños = conflictos raros y merges simples; la rama eterna deviene imposible de integrar** — La integración continua empieza por ramas efímeras.
