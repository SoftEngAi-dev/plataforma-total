# 📖 Glosario — 3. Deshacer: checkout, restore, revert, reset (la tabla salvadora)

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 3 · Términos que debes poder definir sin mirar

- **revert (crea commit inverso sin reescribir la historia ya publicada)** — Reescribir historia compartida rompe a tus compañeros; revert es la forma polite.
- **Apartar cambios sin commit y retomarlos luego (stash pop)** — El cajón rápido: limpio el área, atiendo la urgencia, recupero lo mío.
