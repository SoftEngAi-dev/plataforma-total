# 📖 Glosario — 4. GitHub colaboración real: PRs y forks

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 4 · Términos que debes poder definir sin mirar

- **rama → commits → push → PR → revisión → merge** — El PR con revisión es el corazón del trabajo en equipo moderno.
- **Cuando el repo no es tuyo/no tienes permiso de push (open source)** — Fork = tu copia en tu cuenta, que permite proponer PR al original.
