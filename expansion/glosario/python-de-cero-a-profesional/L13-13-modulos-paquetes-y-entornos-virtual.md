# 📖 Glosario — 13. Módulos, paquetes y entornos virtuales

> Python — De Cero a Profesional · Lección 13 · Términos que debes poder definir sin mirar

- **El código solo corre al EJECUTAR el archivo, no al importarlo** — Permite archivos que son a la vez librería (importar) y script (correr).
- **Con -m, los imports relativos del paquete funcionan; con ruta directa suelen romperse** — -m ejecuta como módulo del paquete: los from tareas import resuelven bonito.
