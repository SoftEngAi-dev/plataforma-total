# 📖 Glosario — 7. Bucles: for, range, enumerate, while

> Python — De Cero a Profesional · Lección 7 · Términos que debes poder definir sin mirar

- **Índice y elemento a la vez, legible y sin errores de off-by-one** — enumerate es el idioma correcto; range(len()) es el acento extranjero.
- **2, 4, 6, 8** — range(inicio, fin, paso) — fin SIEMPRE excluido.
