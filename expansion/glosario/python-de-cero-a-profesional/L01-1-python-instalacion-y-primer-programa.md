# 📖 Glosario — 1. Python: instalación y primer programa

> Python — De Cero a Profesional · Lección 1 · Términos que debes poder definir sin mirar

- **La indentación (sangría) de 4 espacios** — La sangría forzada hace el código universalmente legible — la idea nuclear de Python.
- **str (hay que convertir con int()/float() para calcular)** — Fuente clásica de bugs principiantes: '5' + '5' = '55'. Convierte.
