# 📖 Glosario — 8. Funciones: parámetros, return y scope

> Python — De Cero a Profesional · Lección 8 · Términos que debes poder definir sin mirar

- **Los posicionales deben venir primero para no ambiguar la llamada** — f(5) debe ser claro: a=5. Con default primero sería ambiguo.
- **None (¡cuidado al encadenar!)** — Caso clásico: olvidas return y luego el resultado es None donde no esperas.
