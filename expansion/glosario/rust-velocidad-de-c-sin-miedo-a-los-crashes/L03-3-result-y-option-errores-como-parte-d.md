# 📖 Glosario — 3. Result y Option: errores como parte del tipo

> Rust — Velocidad de C sin Miedo a los Crashes · Lección 3 · Términos que debes poder definir sin mirar

- **Si es Ok, desenvuelve el valor; si es Err, lo retorna inmediatamente a la función llamante (propagación elegante)** — El equivalente Go-verboso pero sin boilerplate: error handling conciso y explícito.
- **No hay null: la AUSENCIA es parte del TIPO y el compilador EXIGE manejar el caso None** — Null = 'agujero invisible'; None = 'la firma te avisa y obliga'. Billion-dollar mistake corregida.
