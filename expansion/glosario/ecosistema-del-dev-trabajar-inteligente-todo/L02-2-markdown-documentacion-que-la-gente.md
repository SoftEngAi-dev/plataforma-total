# 📖 Glosario — 2. Markdown + documentación que La gente lee

> Ecosistema del Dev — Trabajar Inteligente Todos los Días · Lección 2 · Términos que debes poder definir sin mirar

- **El POR QUÉ/contexto no obvio del código (el QUÉ lo dice el código mismo)** — Razones, advertencias y decisiones: lo que futuras lecturas no pueden inferir.
- **Qué hace + demo + install 3 pasos + ejemplo de uso (el lector decide en <1 minuto)** — La claridad al abrir = usuarios/contribuidores que se quedan.
