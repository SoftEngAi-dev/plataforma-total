# 📖 Glosario — 5. Scripts Bash: automatiza tu propia vida

> Linux y Terminal — El Superpoder del Dev · Lección 5 · Términos que debes poder definir sin mirar

- **Sin ellas, valores con espacios se rompen en múltiples argumentos (bugs y desastres)** — rm $f → rm dos cosas si f="mi archivo.txt"; rm "$f" → correcto.
- **Fallar rápido y claramente: el script se detiene ante errores en vez de continuar roto** — Script que sigue tras error suele causar más daño que uno que para.
