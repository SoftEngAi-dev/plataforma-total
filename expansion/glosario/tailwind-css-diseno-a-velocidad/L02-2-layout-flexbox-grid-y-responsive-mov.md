# 📖 Glosario — 2. Layout: flexbox, grid y responsive móvil primero

> 🎨 Tailwind CSS — Diseño a Velocidad · Lección 2 · Términos que debes poder definir sin mirar

- **3 columnas a partir del breakpoint md (768px) hacia arriba** — Tailwind es mobile-first: el base es móvil y los prefijos md:/lg: aplican hacia arriba.
- **con la clase mx-auto (más max-w-* o container)** — mx-auto reparte el margen lateral; text-center solo alinea texto en línea.
