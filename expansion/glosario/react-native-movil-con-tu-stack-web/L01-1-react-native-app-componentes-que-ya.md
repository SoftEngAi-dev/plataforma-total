# 📖 Glosario — 1. React Native: App = componentes que ya sabes

> React Native — Móvil con Tu Stack Web · Lección 1 · Términos que debes poder definir sin mirar

- **RN compila tus componentes a widgets NATIVOS reales (rendimiento verdadero), no embebe una web** — RN renderiza UIView/View nativas: por eso se siente app de verdad, no página.
- **Toolchain que elimina el setup nativo: QR al teléfono, hot reload, build en la nube** — Con Expo arrancas sin Xcode/Android Studio instalado: la puerta de entrada estándar.
