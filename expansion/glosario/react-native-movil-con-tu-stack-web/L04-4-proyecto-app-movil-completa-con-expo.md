# 📖 Glosario — 4. Proyecto: app móvil completa con Expo

> React Native — Móvil con Tu Stack Web · Lección 4 · Términos que debes poder definir sin mirar

- **Expo: instalar Expo Go, correr expo start, escanear el QR en la misma red WiFi** — El QR de Expo convierte tu teléfono en dispositivo de desarrollo instantáneo.
- **Click mantenido: el patrón móvil para acciones secundarias como borrar/editar** — Móvil no tiene botón derecho: long-press = menú contextual.
