# 📖 Glosario — 7. JOINs: consultar varias tablas

> SQL y Bases de Datos — Datos que Persisten · Lección 7 · Términos que debes poder definir sin mirar

- **Los de la tabla izquierda sin coincidencia (con NULLs en la derecha)** — LEFT preserva el lado izquierdo completo: ideal para 'X con o sin Y'.
- **El autor no tiene libros (las NULL no se cuentan en COUNT)** — COUNT(columna) no cuenta NULLs: encaja perfecto con LEFT JOIN para conteos con cero.
