# 📖 Glosario — 3. CSS: selectores, cascada y el modelo de caja

> HTML y CSS — Diseño Web Total · Lección 3 · Términos que debes poder definir sin mirar

- **width/height incluyen padding y border (lo intuitivo)** — Sin él, width:100px + padding te da una caja de más de 100px; con él, es exacto.
