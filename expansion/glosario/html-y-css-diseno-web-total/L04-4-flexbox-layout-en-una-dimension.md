# 📖 Glosario — 4. Flexbox: layout en una dimensión

> HTML y CSS — Diseño Web Total · Lección 4 · Términos que debes poder definir sin mirar

- **display:flex; justify-content:center; align-items:center** — Flexbox con ambos ejes centrados — el centramiento perfecto ya no es chiste.
- **Lo hace crecer para repartir el espacio sobrante del contenedor** — flex-grow/shrink/basis abreviado: típicamente reparte el espacio equitativamente.
