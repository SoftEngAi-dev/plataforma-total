# 📖 Glosario — 7. Variables CSS y tipografía: sistemas de diseño mínimos

> HTML y CSS — Diseño Web Total · Lección 7 · Términos que debes poder definir sin mirar

- **Cambias una línea y actualizas toda la web (sistema de diseño)** — Las variables convierten estilos sueltos en un sistema coherente y mantenible.
- **~45-75 caracteres (65ch) por línea** — Líneas demasiado largas cansan la vista: limita el ancho del texto.
