# 📖 Glosario — 6. Responsive design: una web para todos los tamaños

> HTML y CSS — Diseño Web Total · Lección 6 · Términos que debes poder definir sin mirar

- **Dice al móvil que use el ancho real del dispositivo y no una miniatura** — Sin ella, el móvil renderiza como si fuera un desktop de 980px y escala.
- **Escribir el CSS base para móvil y crecer con min-width media queries** — Base simple en pantalla chica; complejidad progresiva hacia pantallas grandes.
