1. **Explica simple**: «Explica CREATE, INSERT, UPDATE, DELETE: escribir datos como si tuviera 12 años, con una analogía de la vida real y un ejemplo mínimo.»
2. **Sócrates**: «Hazme 3 preguntas sobre CREATE, INSERT, UPDATE, DELETE: escribir datos, una por una, espera mis respuestas y al final dime qué me falta.»
3. **Mini-proyecto**: «Dame un mini-proyecto de 1 hora que use CREATE, INSERT, UPDATE, DELETE: escribir datos, con requisitos claros y sin darme el código.»
4. **Code review**: «Actúa como revisor senior: pídeme mi código donde uso CREATE, INSERT, UPDATE, DELETE: escribir datos y señala errores y mejoras.»
5. **Comparativa**: «Compara CREATE, INSERT, UPDATE, DELETE: escribir datos con 2 alternativas: cuándo usar cada una y errores típicos de cada opción.»
