# 🤖 Prompts para profundizar — 4. Kotlin, Swift, Dart/Flutter, React Native: el mapa móvil

> Tour de Lenguajes — Cuál Aprender y Cuándo · Lección 4 · Cópialos en tu chat IA (Ollama local o el que uses)

1. **Explica simple**: «Explica Kotlin, Swift, Dart/Flutter, React Native: el mapa móvil como si tuviera 12 años, con una analogía de la vida real y un ejemplo mínimo.»
2. **Sócrates**: «Hazme 3 preguntas sobre Kotlin, Swift, Dart/Flutter, React Native: el mapa móvil, una por una, espera mis respuestas y al final dime qué me falta.»
3. **Mini-proyecto**: «Dame un mini-proyecto de 1 hora que use Kotlin, Swift, Dart/Flutter, React Native: el mapa móvil, con requisitos claros y sin darme el código.»
4. **Code review**: «Actúa como revisor senior: pídeme mi código donde uso Kotlin, Swift, Dart/Flutter, React Native: el mapa móvil y señala errores y mejoras.»
5. **Comparativa**: «Compara Kotlin, Swift, Dart/Flutter, React Native: el mapa móvil con 2 alternativas: cuándo usar cada una y errores típicos de cada opción.»
