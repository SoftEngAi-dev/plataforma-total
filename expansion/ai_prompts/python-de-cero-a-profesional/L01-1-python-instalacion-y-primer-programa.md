# 🤖 Prompts para profundizar — 1. Python: instalación y primer programa

> Python — De Cero a Profesional · Lección 1 · Cópialos en tu chat IA (Ollama local o el que uses)

1. **Explica simple**: «Explica Python: instalación y primer programa como si tuviera 12 años, con una analogía de la vida real y un ejemplo mínimo.»
2. **Sócrates**: «Hazme 3 preguntas sobre Python: instalación y primer programa, una por una, espera mis respuestas y al final dime qué me falta.»
3. **Mini-proyecto**: «Dame un mini-proyecto de 1 hora que use Python: instalación y primer programa, con requisitos claros y sin darme el código.»
4. **Code review**: «Actúa como revisor senior: pídeme mi código donde uso Python: instalación y primer programa y señala errores y mejoras.»
5. **Comparativa**: «Compara Python: instalación y primer programa con 2 alternativas: cuándo usar cada una y errores típicos de cada opción.»
