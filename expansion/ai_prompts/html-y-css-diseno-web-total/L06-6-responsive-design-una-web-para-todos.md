1. **Explica simple**: «Explica Responsive design: una web para todos los tamaños como si tuviera 12 años, con una analogía de la vida real y un ejemplo mínimo.»
2. **Sócrates**: «Hazme 3 preguntas sobre Responsive design: una web para todos los tamaños, una por una, espera mis respuestas y al final dime qué me falta.»
3. **Mini-proyecto**: «Dame un mini-proyecto de 1 hora que use Responsive design: una web para todos los tamaños, con requisitos claros y sin darme el código.»
4. **Code review**: «Actúa como revisor senior: pídeme mi código donde uso Responsive design: una web para todos los tamaños y señala errores y mejoras.»
5. **Comparativa**: «Compara Responsive design: una web para todos los tamaños con 2 alternativas: cuándo usar cada una y errores típicos de cada opción.»
