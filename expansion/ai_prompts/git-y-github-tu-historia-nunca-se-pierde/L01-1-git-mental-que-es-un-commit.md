# 🤖 Prompts para profundizar — 1. Git mental: qué es un commit

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 1 · Cópialos en tu chat IA (Ollama local o el que uses)

1. **Explica simple**: «Explica Git mental: qué es un commit como si tuviera 12 años, con una analogía de la vida real y un ejemplo mínimo.»
2. **Sócrates**: «Hazme 3 preguntas sobre Git mental: qué es un commit, una por una, espera mis respuestas y al final dime qué me falta.»
3. **Mini-proyecto**: «Dame un mini-proyecto de 1 hora que use Git mental: qué es un commit, con requisitos claros y sin darme el código.»
4. **Code review**: «Actúa como revisor senior: pídeme mi código donde uso Git mental: qué es un commit y señala errores y mejoras.»
5. **Comparativa**: «Compara Git mental: qué es un commit con 2 alternativas: cuándo usar cada una y errores típicos de cada opción.»
