# 🤖 Prompts para profundizar — 5. .gitignore, tags y limpieza: buen ciudadano del repo

> Git y GitHub — Tu Historia Nunca Se Pierde · Lección 5 · Cópialos en tu chat IA (Ollama local o el que uses)

1. **Explica simple**: «Explica .gitignore, tags y limpieza: buen ciudadano del repo como si tuviera 12 años, con una analogía de la vida real y un ejemplo mínimo.»
2. **Sócrates**: «Hazme 3 preguntas sobre .gitignore, tags y limpieza: buen ciudadano del repo, una por una, espera mis respuestas y al final dime qué me falta.»
3. **Mini-proyecto**: «Dame un mini-proyecto de 1 hora que use .gitignore, tags y limpieza: buen ciudadano del repo, con requisitos claros y sin darme el código.»
4. **Code review**: «Actúa como revisor senior: pídeme mi código donde uso .gitignore, tags y limpieza: buen ciudadano del repo y señala errores y mejoras.»
5. **Comparativa**: «Compara .gitignore, tags y limpieza: buen ciudadano del repo con 2 alternativas: cuándo usar cada una y errores típicos de cada opción.»
