> PHP y Laravel — El Backend Que Alimenta la Web · Lección 1 · Aprender de los errores (propios y ajenos)

- ❌ «let x» → Frente a «¿Cómo se declara una variable en PHP?» lo fácil es confundirse. **Verdad**: $x = valor (el $ es obligatorio en cada variable). El $ marca variables — parece raro y luego te acostumbras.
- ❌ «var x» → Frente a «¿Cómo se declara una variable en PHP?» lo fácil es confundirse. **Verdad**: $x = valor (el $ es obligatorio en cada variable). El $ marca variables — parece raro y luego te acostumbras.
- ❌ «Un número» → Frente a «¿Qué es un array asociativo en PHP?» lo fácil es confundirse. **Verdad**: El equivalente a dict/hash: clave=>valor ['nombre'=>'Ada']. El tipo multiuso de PHP: lista y diccionario en uno.
