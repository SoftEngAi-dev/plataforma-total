# ⚠️ Errores comunes — 1. React: pensar en componentes

> React — Interfaces Modernas y Reutilizables · Lección 1 · Aprender de los errores (propios y ajenos)

- ❌ «Un lenguaje aparte» → Frente a «¿Qué es JSX?» lo fácil es confundirse. **Verdad**: Sintaxis que escribe HTML dentro de JS y llama funciones de React para construir el DOM. JSX describe la UI; Babel/Vite lo convierte en llamadas a funciones.
- ❌ «CSS en JS» → Frente a «¿Qué es JSX?» lo fácil es confundirse. **Verdad**: Sintaxis que escribe HTML dentro de JS y llama funciones de React para construir el DOM. JSX describe la UI; Babel/Vite lo convierte en llamadas a funciones.
- ❌ «Variables globales» → Frente a «¿Qué son las props?» lo fácil es confundirse. **Verdad**: Los datos que un componente recibe de su padre (parámetros del componente). Componente = función; props = sus argumentos. Comunicación de padre a hijo.
- ❌ «Estilos del componente» → Frente a «¿Qué son las props?» lo fácil es confundirse. **Verdad**: Los datos que un componente recibe de su padre (parámetros del componente). Componente = función; props = sus argumentos. Comunicación de padre a hijo.
