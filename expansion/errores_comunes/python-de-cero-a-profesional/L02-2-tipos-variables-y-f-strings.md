# ⚠️ Errores comunes — 2. Tipos, variables y f-strings

> Python — De Cero a Profesional · Lección 2 · Aprender de los errores (propios y ajenos)

- ❌ «3» → Frente a «¿Qué imprime 7 % 2?» lo fácil es confundirse. **Verdad**: 1. % es residuo: 7 = 2×3 + 1.
- ❌ «0» → Frente a «¿Qué imprime 7 % 2?» lo fácil es confundirse. **Verdad**: 1. % es residuo: 7 = 2×3 + 1.
- ❌ «Solo texto» → Frente a «¿Qué permite la f-string?» lo fácil es confundirse. **Verdad**: Interpolar variables y expresiones con formato: f'{precio:.2f}'. Las f-strings combinadas con especificadores de formato son el estándar moderno.
- ❌ «Solo variables» → Frente a «¿Qué permite la f-string?» lo fácil es confundirse. **Verdad**: Interpolar variables y expresiones con formato: f'{precio:.2f}'. Las f-strings combinadas con especificadores de formato son el estándar moderno.
