# ⚠️ Errores comunes — 1. JavaScript: el lenguaje que está en todas partes

> JavaScript — De Cero a Experto · Lección 1 · Aprender de los errores (propios y ajenos)

- ❌ «Solo en navegadores» → Frente a «¿Dónde corre JavaScript hoy día?» lo fácil es confundirse. **Verdad**: Navegadores, servidores, móviles, desktops y más. Con Node y sus derivados, JS es verdaderamente universal.
- ❌ «Solo en servidores» → Frente a «¿Dónde corre JavaScript hoy día?» lo fácil es confundirse. **Verdad**: Navegadores, servidores, móviles, desktops y más. Con Node y sus derivados, JS es verdaderamente universal.
- ❌ «print()» → Frente a «¿Qué imprime en la consola del navegador?» lo fácil es confundirse. **Verdad**: console.log(). console.log es el print de JavaScript — tu aliado n.º 1.
- ❌ «echo()» → Frente a «¿Qué imprime en la consola del navegador?» lo fácil es confundirse. **Verdad**: console.log(). console.log es el print de JavaScript — tu aliado n.º 1.

## 🩹 Antídoto universal
1. Lee el mensaje de error COMPLETO antes de googlear.
2. Pon el error exacto a la IA local y pide explicación, no solución.
3. Documenta el error en tu bitácora: error → causa → fix.
