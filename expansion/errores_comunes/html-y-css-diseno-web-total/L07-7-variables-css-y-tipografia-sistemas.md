- ❌ «Cargan más rápido» → Frente a «¿Qué ventaja da definir colores como variables en :root?» lo fácil es confundirse. **Verdad**: Cambias una línea y actualizas toda la web (sistema de diseño). Las variables convierten estilos sueltos en un sistema coherente y mantenible.
