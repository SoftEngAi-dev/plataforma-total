# ⚠️ Errores comunes — 5. CSS Grid: diseño en dos dimensiones

> HTML y CSS — Diseño Web Total · Lección 5 · Aprender de los errores (propios y ajenos)

- ❌ «3 columnas fijas» → Frente a «¿Qué hace repeat(auto-fit, minmax(250px, 1fr))?» lo fácil es confundirse. **Verdad**: Columnas dinámicas: entran las quepan con mínimo 250px y rellenan el espacio. El patrón responsive por excelencia: se adapta solo al ancho disponible.
- ❌ «250px de alto» → Frente a «¿Qué hace repeat(auto-fit, minmax(250px, 1fr))?» lo fácil es confundirse. **Verdad**: Columnas dinámicas: entran las quepan con mínimo 250px y rellenan el espacio. El patrón responsive por excelencia: se adapta solo al ancho disponible.
- ❌ «Siempre» → Frente a «¿Cuándo elegir Grid sobre Flexbox?» lo fácil es confundirse. **Verdad**: Cuando el diseño es bidimensional (filas y columnas). Flex = una dimensión; Grid = dos. Conviven felices.
- ❌ «Nunca» → Frente a «¿Cuándo elegir Grid sobre Flexbox?» lo fácil es confundirse. **Verdad**: Cuando el diseño es bidimensional (filas y columnas). Flex = una dimensión; Grid = dos. Conviven felices.
