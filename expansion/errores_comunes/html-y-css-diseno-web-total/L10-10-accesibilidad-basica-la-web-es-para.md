# ⚠️ Errores comunes — 10. Accesibilidad básica: la web es para todas las personas

> HTML y CSS — Diseño Web Total · Lección 10 · Aprender de los errores (propios y ajenos)

- ❌ «<div onclick=...>» → Frente a «¿Qué elemento es correcto para acción clickeable accesible?» lo fácil es confundirse. **Verdad**: <button>. <button> trae gratis: foco de teclado, Enter/Espacio, y semántica para lectores de pantalla.
- ❌ «<span onclick=...>» → Frente a «¿Qué elemento es correcto para acción clickeable accesible?» lo fácil es confundirse. **Verdad**: <button>. <button> trae gratis: foco de teclado, Enter/Espacio, y semántica para lectores de pantalla.
- ❌ «2:1» → Frente a «¿Cuál es el contraste mínimo texto/fondo recomendado?» lo fácil es confundirse. **Verdad**: 4.5:1. WCAG AA: 4.5:1 para texto normal (3:1 para texto grande).
- ❌ «3:1» → Frente a «¿Cuál es el contraste mínimo texto/fondo recomendado?» lo fácil es confundirse. **Verdad**: 4.5:1. WCAG AA: 4.5:1 para texto normal (3:1 para texto grande).

## 🩹 Antídoto universal
1. Lee el mensaje de error COMPLETO antes de googlear.
2. Pon el error exacto a la IA local y pide explicación, no solución.
3. Documenta el error en tu bitácora: error → causa → fix.
