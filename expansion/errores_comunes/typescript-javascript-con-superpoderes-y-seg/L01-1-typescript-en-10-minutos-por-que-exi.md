# ⚠️ Errores comunes — 1. TypeScript en 10 minutos: por qué existe

> TypeScript — JavaScript con Superpoderes y Seguridad · Lección 1 · Aprender de los errores (propios y ajenos)

- ❌ «Un lenguaje distinto a JS» → Frente a «¿Qué es TypeScript exactamente?» lo fácil es confundirse. **Verdad**: JavaScript + chequeo estático de tipos que se compila a JS puro. Superconjunto tipado: corre como JS tras compilar — el navegador jamás ve tipos.
- ❌ «Una librería de JS» → Frente a «¿Qué es TypeScript exactamente?» lo fácil es confundirse. **Verdad**: JavaScript + chequeo estático de tipos que se compila a JS puro. Superconjunto tipado: corre como JS tras compilar — el navegador jamás ve tipos.
- ❌ «En producción» → Frente a «¿Cuándo detecta TypeScript los errores de tipo?» lo fácil es confundirse. **Verdad**: Al editar/compilar, antes de ejecutar. Shift-left: el error aparece cuando lo escribes, no cuando el usuario lo encuentra.
- ❌ «Nunca» → Frente a «¿Cuándo detecta TypeScript los errores de tipo?» lo fácil es confundirse. **Verdad**: Al editar/compilar, antes de ejecutar. Shift-left: el error aparece cuando lo escribes, no cuando el usuario lo encuentra.
