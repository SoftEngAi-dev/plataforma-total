> C# y .NET — El Ecosistema Microsoft Moderno · Lección 2 · Aprender de los errores (propios y ajenos)

- ❌ «Lento» → Frente a «¿Qué es una Minimal API en .NET?» lo fácil es confundirse. **Verdad**: El estilo conciso de ASP.NET Core: rutas con lambdas en Program.cs sin controladores pesados. Equivalente .NET a Express/Flask: ideal para APIs y microservicios.
