# ⚠️ Errores comunes — 1. React Native: App = componentes que ya sabes

> React Native — Móvil con Tu Stack Web · Lección 1 · Aprender de los errores (propios y ajenos)

- ❌ «Son iguales» → Frente a «¿En qué difiere React Native de una WebView/web app empaquetada?» lo fácil es confundirse. **Verdad**: RN compila tus componentes a widgets NATIVOS reales (rendimiento verdadero), no embebe una web. RN renderiza UIView/View nativas: por eso se siente app de verdad, no página.
- ❌ «Es HTML nativo» → Frente a «¿En qué difiere React Native de una WebView/web app empaquetada?» lo fácil es confundirse. **Verdad**: RN compila tus componentes a widgets NATIVOS reales (rendimiento verdadero), no embebe una web. - ❌ «Otro lenguaje» → Frente a «¿Qué hace Expo en el flujo RN?» lo fácil es confundirse. **Verdad**: Toolchain que elimina el setup nativo: QR al teléfono, hot reload, build en la nube. Con Expo arrancas sin Xcode/Android Studio instalado: la puerta de entrada estándar.
