# 🧠 Mapa mental — Herramientas del Desarrollador

```
Herramientas del Desarrollador
├─ El editor de código: tu casa de trabajo
│   └─ 💬 ¿Qué hace Ctrl+P en VS Code?
├─ La terminal: miedo fuera
│   └─ 💬 ¿Qué comando muestra en qué carpeta estás?
├─ Instalar y gestionar paquetes (todo por terminal)
│   └─ 💬 ¿Para qué sirve un virtualenv en Python?
├─ Git: la memoria eterna de tu código (básico)
│   └─ 💬 ¿Qué hace git add antes del commit?
├─ GitHub: publica y colabora
│   └─ 💬 ¿Qué hace `git push -u origin main`?
└─ Debugging: el arte de encontrar lo que rompiste
│   └─ 💬 ¿Cómo se lee un traceback?
```

🖨 Versión imprimible para tu pared: jerarquía = recorrido visual de memoria.
